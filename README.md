Random Pokémon Generator

A fun, interactive web application that fetches and displays a random Pokémon whenever you click a button. The app pulls live stats, artwork, and real game audio cry elements directly from the public [PokeAPI](https://pokeapi.co). 

## Live Demo
https://ulyssesgthb.github.io/Pokemon-API-fetch-Practice/

## Features
    Randomizer Button:   Instantly fetches a random Pokémon from the database with a single click.
    Audio Cries:   Plays the official retro Pokémon sound/cry whenever a new Pokémon appears.
    Live Data Fetching:   Dynamically pulls high-quality official artwork, types, and base stats.
    Responsive Design:   Completely styled with CSS to look great on desktop, tablet, and mobile screens.

## Tech Stack
    HTML5:   Semantic layout structure for the card and controls.
    CSS3:   Custom styling, hover animations, and a responsive layout.
    JavaScript (ES6):   Asynchronous functions using `fetch` and `async/await` to generate random IDs, fetch data, play audio, and update the DOM.

## How to Run Locally

Because this project uses vanilla frontend technologies, you do not need to install anything! 

1.   Clone the repository:  
   ```bash
   git clone https://github.com/UlyssesGtHb/Pokemon-API-fetch-Practice
   ```

2.   Navigate into the folder:  
   ```bash
   cd your-repo-name
   ```

3.   Launch the app:  
     Simply double-click your `index.html` file to open it in your preferred web browser.
      Alternative:  If you use VS Code, right-click `index.html` and select   "Open with Live Server"   for automatic browser refreshing.
